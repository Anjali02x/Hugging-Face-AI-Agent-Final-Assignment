# GAIA Question-Answering Agent (Hugging Face Agents Course)

Final assignment for the Hugging Face Agents Course. The agent fetches questions from the course API, answers them using web search and attached files, and submits the answers for scoring.

## Features
- Web search (DuckDuckGo) for context
- Reads Excel, CSV, and Python files, and transcribes audio with Whisper
- Formats short answers for exact-match grading
- Retries on errors and rate limits

## Tech
Python, Google Colab, Groq API, pandas, requests

## Result
Score: 35/20

## How to run
1. Open the notebook in Colab.
2. Save a free Groq API key in Colab Secrets as "Groq_Api_Key"
3. Run the cells in order.
